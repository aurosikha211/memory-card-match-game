
# Memory Match Game

An interactive browser-based memory game built with HTML5,
CSS3, and Vanilla JavaScript.

## About the Project

The goal is to find matching pairs of cards while tracking
moves, time, level progress, and rewards.

## Features

- 4 x 4 card grid
- Matching-pair gameplay
- Timer and move counter
- Coin rewards and reveal power-up
- Multiple levels
- Pause, resume, and restart controls
- Sound effects and completion animations
- Responsive layout
- Designer profile links

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Concepts Practiced

- DOM manipulation
- Event handling
- Arrays and functions
- Randomization and conditional logic
- Timers and game-state management
- CSS Grid and Flexbox
- Responsive design

## Getting Started

1. Clone or download this repository.
2. Keep index.html, style.css, and script.js
   in the same project folder.
3. Open index.html in a modern browser.
4. Start playing!
